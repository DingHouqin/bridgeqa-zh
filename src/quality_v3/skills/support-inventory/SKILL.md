# 来源支持登记

在Origin／Composer准备家族变换时使用。输入是已确定的来源片段和查询；不添事实、不改写原文来补可选条件。

为每条查询事实记录支持它的各组逐字引文、单元ID、scope及必要的指代先行词。组内多句共同支持是合取；多组分别独立支持同一事实才是重复表达。前后重复叙述不能因只登记其中一处而被视为不存在。

另登记从查询起点到同一答案的完整合法路径。换用同一条事实的同义表达不是独立证明；路径中的关系事实改变、且其余步骤仍由当前文本独立支持，才属于另一完整证明。保留父／母角色、时间／事件和陈述范围，不能把梦境或未触发条件接到现实链。

设计删证时检查整个实际交付文本：删掉一组表达后另一组是否仍在；破坏一条链后另一条是否仍完整；起点名称是否在未补写的原材料中保留。逐字删除和登记图重算由程序执行；引用失配触发复核，不证明语义消失。

缺少可选成员时区分：not_constructed（本轮未完成登记或构建）、not_applicable（核对给定范围后没有适用结构，附检查依据）、unresolved（尚有解释分歧）。“没有登记”只能支持第一种，不能证明第二种。没有发现替代路径也不保证穷尽自然语言支持。

事实缺失、夫妇关系不足以确定亲生父亲或范围不清时直接记录拒收／待审，不借外部关系库补gold。输出支持清单和覆盖状态，不自行批准题库发布。
