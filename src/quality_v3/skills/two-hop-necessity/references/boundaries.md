# 关系表达边界

| 当前材料与任务 | 判断依据 |
| --- | --- |
| “明是宁的父亲，宁是松的父亲。”问松的祖父 | 两条关系在一句中，仍须组合。 |
| 上述材料又写“松的祖父是明” | 存在直接目标关系；原有两步证明存在不能消除捷径。 |
| “明不是松的祖父”，另有完整合法父系链 | 否定句不是支持明的直答捷径；还须核验文本是否冲突。 |
| 现实只给第一跳，梦境声称第二跳，问题只采用现实 | 不能跨scope补链；若候选证据不足可合法接受。 |
| “松的外祖母是岚”，问松的父亲的母亲 | 不同亲属角色，不是该查询的直接答案。 |
| 删除原注释后仍写“松的父亲叫宁” | 支持未消失；不能用旧quote缺失裁定缺证。 |

这些是判别标准的例子，不是目标人物关系库。对别名、反事实、否定和条件只使用当前材料的约定。
