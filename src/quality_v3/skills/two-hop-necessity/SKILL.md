# 两步必要性审查

应用于基础题及仍可答变体的多跳有效性审查。判断的是目标结论是否必须组合两个关系，不是“能否写出两个步骤”。不以段落数、引文数或图中边数代替必要性。

从问句确定起点、每步父／母角色、目标及允许的陈述范围。先在本成员材料中寻找直接陈述该目标的关系句，包含目标称谓、别名和可由同段消解的指代。例如问“某人的父亲的父亲”，材料直接写其祖父姓名，即使另有完整父系链，仍存在捷径。目标是父系祖母时，外祖母关系不构成同一结论。

发现疑似捷径时，定位实际关系句，核对主体、目标角色、肯否、现实／梦境及条件。单纯出现答案名字、祖辈称谓、否定的目标关系或不适用的梦境说法，不能直接判捷径。程序扫描只提供复核线索。

未发现直接结论后，检查两次必要操作是否各有当前材料支持，是否有只用一个事实的其他合法读法。同一句包含两条父子事实，仍可能必须组合两步；别名映射、同段连续阅读和一条宽引文不自动降低跳数。合法实例与容易误判的边界见[关系表达边界](references/boundaries.md)。

结论写入调用方Schema规定的两步必要性字段（本版本为two_hop.verdict）：确认必要为 necessary；找到合法省步读法为 shortcut，并给当前材料的逐字引文；真正缺证任务为 not_applicable；范围或身份不足以判定为 undetermined。不要把“我未找到”升级为枚举了全部自然语言证明的保证。

若候选声明是证据不足，还应核对残余重复表达和其他完整合法链；引文失配不能证明支持消失。审查发现直接结论泄漏时，候选答案可以正确，但它仍不满足必要两步的任务要求，不能 pass。
