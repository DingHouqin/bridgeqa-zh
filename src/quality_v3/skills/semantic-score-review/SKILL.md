# 语义评分复核

复核候选答案时，分别判断状态、顶层答案、逐步证明和引用支持。材料与允许的查询范围优先于登记图；参考图是可核验关系清单，不替代材料，也不保证没有合法替代证明。该技能不把裁判判断称为人工真值。

顶层答案独立计分。步骤正确到达目标，不能救回顶层填写中间人物的错误；正确答案也不能救回无效证明。证据不足应有空答案和空步骤，解释另行检查，不把局部正确当成整个任务正确。

只在当前材料已建立同一身份时接受别名和组合称谓。登记的两个名称在“名称甲（名称乙）”中指向同一人，可以等价；跨人物混合、指向不明的同名、仅含正确名字的描述性短语不能靠子串命中通过。保守实体解析遇到歧义时保留不确定，不按gold偏好选择。例子见[别称与引用判别](references/scoring-boundaries.md)。

逐条检查提交引文在该成员上下文中存在，且引文确实承载该步关系。引文中的代词可由同一上下文的先行词消解，不强求短引文重复全名。不同于登记区间的另一处明确表达也可合法支持；仅仅未与旧span相交不能判错。相反，引用只提名字、无关景物、否定关系或不适用梦境，即使全文其他位置有正确事实，也不能算这条引用支持了证明。

允许当前文本中的其他合法两步路径，但须满足查询角色与scope，不能凭作品知识补边。引用定位成功只证明复制准确；关系蕴含仍须核验。提供精简的逐步支持依据与实际引文，不输出长篇思维过程。

输出合同内的状态／答案／证明支持结论及 findings。缺少足够材料核验的事项标 undetermined 交复核，不把语义待审伪装成错误或成功。程序保留旧严格分、修订结构分及本次语义判断三层，不静默覆盖历史分数，不自动放行题库。
