# 人工审查同步服务

界面仍在[原网站05](https://dinghouqin.github.io/bridgeqa-zh/#/review)，本站仅提供数据库接口。接口源文件见[Worker](worker.js)，字段校验复用[审查模型](../web/review-model.js)，规格见[人工审查规格](../specs/08_临时人工审查.md)。

托管于Sites，使用D1持久化，不使用浏览器作为进度真值。用户明确选择持有链接即可使用；按A/B/C/D编号和姓名简写署名，不作为身份认证。支持带版本号的条件写入，冲突返回409，前端保留输入并明确选择版本。只接受当前题库和登记题号的结构化记录，不能通过接口改变题目或分配。原始benchmark复核字段保持不变。

[准备脚本](prepare.mjs)复制当前数据版本、分配清单和共享校验逻辑。正式发布从[工作区独立服务副本](../../workspace/human-review-site/)进行，该副本与主仓库隔离；由Sites发布工具推送和打包。需要先在[服务目录](./)安装声明的Drizzle开发依赖，生成并检查[迁移目录](drizzle/)，再执行构建。发布成功后更新[验收记录](../../workspace/explorer/README.md)。

新增数据版本时生成新的round，已完成审查不会自动迁移到内容变化后的题库。现阶段共享读取每5秒刷新，输入停止650毫秒后保存；完成状态必须经服务器成功保存才能显示为共享进度。
