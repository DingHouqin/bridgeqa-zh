# 05｜验收与测试

[规格入口](README.md) · [候选集口径](../../data/pilot_literature_history_v0/README.md)

| 编号 | 验收点 | 具体通过条件 |
| --- | --- | --- |
| A01 | 先规格后实现 | 先落盘本规格系列，再创建运行代码。 |
| A02 | 概览 | 显示文学/历史主题、128记录/20家族、27实际单元/32候选、4来源，10组合与开发候选状态；58 Oracle另列。 |
| A03 | 数据集选择 | 当前数据集可选；无效ID有恢复入口；更换后旧筛选清空。 |
| A04 | 全量题库 | 默认128记录、20家族，分页；每题实际场景完整可见，全部设计/元信息标签可展开和筛选。 |
| A05 | 筛选与定位 | 场景ANY/ALL、跨维度AND、维度内OR；文本搜索、零结果、清空、URL刷新及返回结果保持正确。 |
| A06 | 普通题 | C01三跳与对应支持可看，潜在错角色分支可见且不叫已验证干扰。 |
| A07 | 替代证明 | C04 challenge可切两证明，材料颜色与支持随选择改变；delete_one仅S01，删全部无当前合法证明。 |
| A08 | 分支操作 | C02比较有两支；C06表文材料和筛选/求和操作可见，深度5与操作数分开。 |
| A09 | 特殊状态 | C03显示两身份解释及别名消解；C09不确定为可答；no_context无当前材料，不伪造正确链。 |
| A10 | 反事实与配对 | C08新答案、改写前引文、两条改边、命名映射、同材料换起点/同答案异证明均可访问。 |
| A11 | 原始资料 | 可定位资料ID、事实与quote、原网页；背景全文可展开；不遗漏表格或原材料顺序。 |
| A12 | 安全和数据一致 | 不更改源数据；未知数据集/路径穿越被拒绝；数据文本转义；全部记录支持与来源索引无悬空引用。 |
| A13 | 浏览器与视觉 | 概览/题库/详情真实交互通过，无脚本异常；1440桌面和390窄屏可用，资料文字可读，截图保留。 |
| A14 | 交付 | 可运行入口、规格目录、测试说明及实际限制清楚；不把潜在干扰推定当人工复核或模型观察。 |
| A15 | 固定测试指引 | 侧栏03可进入；无数据集bundle请求；即使URL带未登记数据集也显示相同内容；刷新和窄屏可用；pilot的全部文件用途、输入边界、配对和节点诊断方法有说明。 |

若浏览器控制能力无法使用，可用本机已提供的浏览器自动化验证；若连该能力也不可用，保留HTTP/结构测试并明确未完成的视觉范围，不能伪称全验收通过。
