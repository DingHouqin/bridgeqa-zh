# 全量题目与最新Luna公开投影

[发布规格](../specs/11_全量题库与最新关系题发布.md) · [投影构建器](../build_catalog.py)

[题目清单](catalog.json)含570条输入记录：（86＋58 Oracle）＋（57＋10无材料）＋252＋18＋16＋49＋24。最新v24为8新增母题、16部分换名变体；主任务、变体与诊断分别保留类型，不把跨批复用当成独立母题增加。每条input逐字值等于原实际输入，input_sha256为排序键紧凑UTF-8 JSON的哈希。

[Luna原答与裁决](luna.json)只含当前24槽，23份原答逐字保留；17正确、4错误、2语义未决，另1技术缺失未重试。旧N02的3份无效答卷不计入当前结果。JSON、引文问题和终点结果单列，未决不改判成功；本轮没有重新调用模型。

[来源与哈希](manifest.json)只登记相对审计路径和SHA；这些路径不代表源文件已公开。公开input可用于逐题盲解，清单中的元数据和模型答卷不能一起发给被测模型。不发布独立金标、关系证明、换名映射、原生事件、会话或机器环境。旧v18结果保持原冻结字节。

公开CI可运行构建器的--verify-existing，校验已发布快照，不需要私有实验记录。
