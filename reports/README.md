# 课程交付

从报告大纲开始写，引用版本化数据和真实运行记录。课程最终报告可用 Word/PDF，正文不超过 8 页（参考文献与附录除外），须明确成员贡献、数据/模型来源、AI 使用和展示/报告差异。Markdown 大纲不是最终提交格式。

最终私有压缩包另带完整源代码、自建数据与材料；不要只交 Git 跟踪的公开部分。命名与截止时间见课程要求对应表。

## 使用顺序

1. 阅读 [项目意义与贡献定位](../docs/18-purpose-and-contributions.md)。
2. 按 [贡献验证计划](../experiments/plans/contribution-validation.md) 收集实际材料。
3. 根据 [期中](midterm-outline.md)、[期末](final-outline.md)、[演示](demo-plan.md) 大纲组织叙事。
4. 用 `contribution-evidence.template.csv` 登记 C1–C4 的状态和材料路径。状态为 planned/implemented/observed/supported；模板未填结果。

建议复制登记表到 `experiments/private/contribution-evidence.csv` 填真实信息。公开版只列允许公开的开发证据与汇总；不把隐藏逐题 ID、gold 或预测内容填入本目录的公开文件。证据路径不代表已经完成审核，必须填写实际版本、运行与复核信息。

课程权重与项目证据的映射不是教师额外评分细则，不承诺分数。报告的效果主张与当前实现/真实实验一致。
