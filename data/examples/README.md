# 纯虚构夹具

`samples.jsonl`：9 个样本、3 个虚构 seed。三跳 seed 包含 ZZZ gold_only、ZZZ 普通/攻击对、ZEZ 普通/攻击对；二跳、四跳 seed 各有普通/攻击对。林牧、林墨、北澜研究所、南泽研究所、星桥图、青屿市、海临市、云澜省、墨辰省全部为虚构实体。

`predictions.jsonl`：人工填写，ZZZ 攻击例故意答错，ZEZ 攻击例答对。它只能检查程序算分，不能证明任何模型或语言效果。`model-input.json` 演示向模型提交的去标签结构。

控制文档与干扰文档保持数量和位置；未进行严格 token 长度匹配，所以不能用于正式因果比较。各跳正式样本仍需真实来源和人工审核。三个 seed 的变体数不同，参考评分器先按 seed 聚合，不把多个语言变体当独立题。
