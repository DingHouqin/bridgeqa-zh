# 实验

`plans/` 保存结果出现前的实验计划；`run-manifest.template.json` 复制后填写完整运行信息。真实输出和隐藏指标放 `private/` 或 `artifacts/`，得到公开授权后才转入报告。当前不存在真实实验结果。

执行顺序：[试运行](plans/pilot.md) → [主实验](plans/main.md)。[贡献验证计划](plans/contribution-validation.md) 将 C1–C4 关联到 E1–E5，其中 E2/E4 共用主实验，E5 可选。贡献证据登记表及报告要求见 [reports](../reports/README.md)，新增指标实施状态见 [工具状态](../docs/16-implementation-status.md)。
