# 主实验计划草案

P0 主实验：纯中文、单领域、固定候选证据，比较匹配普通/攻击输入。三跳为主分析、二跳为基础覆盖、四跳为小规模压力测试。范围与数量以 [设计草案](../../docs/17-benchmark-spec-proposal.md) 和建议配置为准，尚未冻结。

B 组使用公开开发集优化；同基座 B0/B1 在相同冻结隐藏题、输出协议和资源上限上比较，并报告实际成本。已有 Answer EM/支持 F1/简单配对指标与待实现 Strict SR、Path-CFS 明确区分；独立 Oracle-CS / oracle-prefix 作单独诊断。

主攻击全种子配对，冗余/关系混淆复用共同的小子集。按攻击、二三四跳及来源标签有限分层，实际存在翻译来源时再单列原生/翻译。歧义与反向采用自身任务 gold，不并入保持原答案的上下文攻击。

研究问题、验收与实际材料见 [贡献验证计划](contribution-validation.md) 的 E1–E4。E5 Schema 构题成本为可选，不另造主实验题集。

P1 扩展：同图中英证据、固定语料检索、复杂图或跨领域复核，只有 P0 完成且资源允许时开展。中英先参照既有语言条件文档；检索另报 Recall@k 与端到端结果，均与 P0 分开。

冻结项：采样/split/source_cluster、数据哈希、模型 revision、prompt、解码/解析、调用与 token 上限、攻击机制、主指标、失败处理和统计方法。时间、负责人、样本数与 CI 方法仍待实际确定；当前无真实结果。
