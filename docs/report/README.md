# 报告归档

本目录保存评估与进展的日期快照；持续推进的任务和验收标准放在 [工作计划](../工作计划.md)。

| 日期 | 报告 | 用途 |
| --- | --- | --- |
| 2026-10-07 | [项目进展报告](2026-10-07_项目进展报告.md) | 已完成内容、验证证据与尚未闭合的缺口。 |
| 2026-10-07 | [评分器可执行性评估](2026-10-07_评分器可执行性评估.md) | 评分实现所缺的协议、语义与校准条件。 |
| 2026-10-07 | [在线文档网站可行性评估](2026-10-07_在线文档网站可行性评估.md) | 静态网站方案的评估记录。 |
| 2026-10-07（归档日期） | [研究设计参考报告](2026-10-07_研究设计参考报告.md) | 既有参考材料，原始写作时间未确认，内容保持不变。 |

文件命名采用 `YYYY-MM-DD_报告名.md`，日期按上海时区记录评估或进展快照时间。同一天产生多个版本时采用 `YYYY-MM-DD_HHMM_报告名.md`，保留旧快照并在本目录新增索引；不覆盖旧报告来冒充新时期的记录。既有报告写作时间无法确认时，前缀只表示归档日期，须在索引注明。

参考报告仅供参考，不用于确定题目、数据源、场景、规模、技术路线或评测指标；原有边界见 [项目工作规范](../../AGENTS.md)。本目录不替代 [独立文献调研](../benchmark-survey/README.md) 或 [实际数据与构建说明](../../data/pilot_literature_history_v0/README.md)。
