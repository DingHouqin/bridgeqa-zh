# 逐跳诊断

Gold 是有来源句支持的实体关系图，模型输出是提交的证据与路径。两者一致只能说明输出受支持，不能证明模型内部真实按该链计算。

三跳保存中间实体 B、C 与最终 Y。线性链找最早不一致 hop；并列/交集图需专用匹配，不简单按数组 index 判断。

| 观察到的失败 | 证据 | 后续诊断 |
|---|---|---|
| 检索漏证据 | gold 未进入 Top-k | 给完整 gold 后重答 |
| 实体对齐失败 | 中英别名被当成不同实体 | 受控提供别名映射，单独运行 |
| 首跳选择错误 | 输出 B 或 hop1 支持句错误 | 给正确 B 后重答 |
| 中跳关系错误 | B 对、C 错 | 给正确 B/C 前缀后重答 |
| 末跳错误 | B/C 对、Y 错 | 给正确末跳证据并检查关系/答案表达 |
| 表达/格式错误 | 规范实体正确、文本或 JSON 不符合接口 | 单列输出层失败 |
| 答案对但证据错 | canonical answer 对、支持或链不成立 | 记为答案成功、证据失败 |

Oracle-prefix 是独立干预条件。干预输入不算正常模型可见输入，不能把干预恢复后的答案并入主要正确率。恢复表示在该干预下有能力，不能排除提示变化、答案泄漏或额外信息的作用。

若 B 组仅输出答案，主评测继续答案协议；另做结构化诊断运行，说明输出要求会改变行为。完整自然语言 CoT 不作为必须提交或唯一审核依据。
