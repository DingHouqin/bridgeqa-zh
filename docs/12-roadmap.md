# 相对周计划

历史讨论给出约一月期中、三月期末；准确日期未知。本表为相对 12 周实施建议，课程正式提交以第 18 周周五 24:00 为准，不能由本表推算取代。

| 周 | 交付 | 验收 |
|---|---|---|
| 1 | 角色/A-B 合同草案、领域 pilot、来源与 schema | 每种 hop 约 20 道试题，统计耗时和无效率 |
| 2 | 标准化 loader、三种上下文、两类生成器 | 中文和翻译样例都可结构检查和独立审核 |
| 3 | 一个许可/参数合规 baseline、公开 dev、评分 | 数据→预测→指标可重跑；真实结果与夹具分开 |
| 4 | 期中 mini benchmark、数据分布、失败例、演示 | 完整闭环；约 100–200 对为建议目标，不强凑数 |
| 5–6 | 三跳主集、五类课程任务、双语小样本 | 交叉审核完成，query/context 分协议 |
| 7–8 | 扩量、来源/split 审核、隐藏冻结 | 各种子变体不跨集；B 组有各跳开发样例 |
| 9 | 冻结 baseline / B 优化前后版本主实验 | configs / hashes / revisions / logs 齐全 |
| 10 | 目标跳与语言切片、prefix 干预、CI | 首要研究问题有结果；探索性结论注明 |
| 11 | 数据与报告冻结、私有交付包 | 正文 <=8 页；图表可追溯运行 |
| 12 | 演示、复现与材料核对 | 无网络可展示缓存，解释与报告的差异 |

## 收缩规则

审核成为瓶颈时停止扩展新因素，优先已定义三跳主集；四跳质量差时降低比例；模型 clean-correct 太少时不强算 ASR，检查题目/模型与证据指标；隐藏泄漏则重切分并记录；GPU 不足先减少模型矩阵与实时运行，不降低 gold 质量。

最终规模由 pilot 决定。原报告期中 300–500、期末 800–1200 对属于冲刺建议，不作为当前必达目标。
