# 02｜冗余文本、替代推理链与反事实陷阱

[返回入口](README.md) · [资料目录](00_范围与资料目录.md)。本报告区分“不相关”“相关但无用”和“能导向另一答案”的干扰。

## 1. 普通 distractor 与图结构冗余

[HotpotQA 官方设置](https://hotpotqa.github.io/) 的检索干扰使模型需要从候选段落选证据，但“八段干扰”并不说明八段分别形成了错误推理链。[MuSiQue 构建 §5 S6](https://aclanthology.org/2022.tacl-1.31.pdf) 从其他高质量单跳支持段落中选择干扰，降低金证据与噪声的表面差异。

[CLUTRR §3.5](https://aclanthology.org/D19-1458.pdf) 则给出明确的三类官方噪声：完全不接触目标路径的 disconnected facts；与目标路径只共享一个端点的 irrelevant facts；两个端点都在目标路径上的 supporting facts。第三类可能形成额外的有效推导，所以“冗余证据”不等同于“错误证据”。

**本调研归纳。** 采样噪声时应记录与正确路径共享的节点、边和关系。随机无关材料可测负荷；共享实体的岔路可测证据选择；额外有效路径可测多证明容忍。这三者不能统一标成假事实。

## 2. ACL 2019 ADDDOC：保留答案，切断假的桥接

[ADDDOC 方法 §2.2 与实验 §4](https://aclanthology.org/P19-1262.pdf) 复制含答案的支持文档，替换答案，再替换文档标题/桥接实体，保留能吸引词面匹配的语句。桥接替换是关键：如果仅改答案但仍连着原始第一跳，会直接制造与金答案冲突的有效链。论文比较每个含答案支持文档增加 4/8 篇对抗文档，以及随机插入/前置两种位置；原比较题保留不改。

**中文示意。**

- 正确段一：《潮声》的作者是林澄。
- 正确段二：林澄任职于远帆社；远帆社总部位于望江市。
- 问题：《潮声》作者任职机构的总部在哪个城市？答案：望江市。
- 干扰段：晨舟社总部位于东浦市，并有与正确段近似的出版描述。

干扰给出同类型假答案“东浦市”，但晨舟社未与林澄的任职事实连接。若写成“林澄任职于晨舟社”且没有时间/角色区分，便不再是合格的答案保持攻击。

**机制。** 诱惑来自后半问“总部在哪”与假段的高重合；正确操作是先确认任职机构，再查该机构属性。原作者的标题替换假设有适用范围，中文实体别名与正文共指可能仍把假链接回正确主体，需要全文实体检查。

## 3. EMNLP 2024 Plausible Distractors：连续但偏离条件的假链

[原文 §3](https://aclanthology.org/2024.emnlp-main.147.pdf) 将两跳题分解，提取可改的关键修饰信息；对命名实体生成同类型替代，对其他词使用受约束替换，再让 LLM 生成相互连接的干扰段落。对原问题来说，这些段落可形成看似合理但条件不符的路径。它用干扰替换原非金段落，保持两金八干扰的**段落配比**；这不保证逐 token 等长。

**中文示意。**

| 项目 | 正确路径 | 干扰路径 |
|---|---|---|
| 问题限定 | 星河队的“常规赛主场” | 与球队相关的“季后赛场地” |
| 第一跳 | 星河队→常规赛主场→明川馆 | 星河队→季后赛场地→望湖馆 |
| 第二跳 | 明川馆→容量→4,000 | 望湖馆→容量→4,500 |
| 问题 | 星河队的常规赛主场能容纳多少人？ | 干扰支持的是另一限定下的问题。 |

这类题不用明显胡言乱语就能诱导答案 4,500。决定性差异可能只有“常规赛/季后赛”“创办/收购”“现任/前任”几个字。验收必须证明干扰适用于别的条件，不能靠标注者宣布它“错误”。

## 4. CofCA：先改世界，再为新世界出题

[CofCA v5 §3.1](https://arxiv.org/html/2402.11924v5) 先替换 Wikipedia 段落的实体、名词短语等，结合改写、回译与人审，再基于新段落生成 2/3/4 跳主问题、子题和答案。作者强调降低记忆复现与污染影响。其主问题是在改写后生成的，不应误写成“对原始题只加入干扰”。正式发表已由 [ICLR 2025 页面](https://proceedings.iclr.cc/paper_files/paper/2025/hash/2628d4d3b054c2d7ad33ab03435204f4-Abstract-Conference.html) 核验。

**候选迁移。** 在显式封闭的架空世界中，令甲作品作者为乙、乙所在组织为丙、丙成立地为丁；问甲作品作者所在组织成立于哪里。标准答案是丁，即使真实世界有同名作品的其他答案。这个任务测“遵从给定世界”，不能同时用真实世界知识否定架空事实。

## 5. CRiT-QA：反事实链与多锚点岔路的组合

[CRiT-QA §3](https://aclanthology.org/2026.lrec-1.410.pdf) 从 MuSiQue 分解抽取 SRO 链，保留原问题起点及关系，以虚构对象替换原链实体，并传播替换到后续主语，生成对应段落与新答案。再在不同跳处生成分岔链，使用同类型对象和语义有别的关系，并为独有干扰边生成文本。保留关系区别使路径看似连贯却不满足原查询。

**本调研据此设计的三跳示意。** 正确链：作品甲→作者乙→受雇组织丙→总部丁。

| 岔路位置 | 干扰链的关键改变 | 为什么不支持原问题 |
|---|---|---|
| 第 1 跳 | 作品甲→编辑戊→受雇组织己→总部庚 | 编辑不是作者。 |
| 第 2 跳 | 作者乙→顾问服务组织辛→总部壬 | 服务对象不是受雇组织。 |
| 第 3 跳 | 组织丙→分部所在地癸 | 分部所在地不是总部。 |

这张表是**本项目示意**，不是对原数据每条干扰链的逐条复刻。原论文的自动生成不自动证明所有实例具有唯一解；本项目若采用该机制，需额外用结构与文本双重检查排除意外有效链。

## 6. RGB 与 LV-Eval 提供的补充控制

[RGB 原论文](https://arxiv.org/abs/2309.01431) 区分噪声鲁棒性、无答案时拒答、多信息整合和反事实鲁棒性，且覆盖中英文；它是 RAG 能力诊断而非全员多跳测试。[LV-Eval 作者说明](https://github.com/infinigence/LVEval) 使用混淆事实插入与关键词/短语替换，分别增加近似干扰和降低知识泄漏。它们提示“增加长度”和“更换知识”应拆开做对照。

## 7. 可落地的生成与验收骨架（本调研建议）

1. 先生成或采集真实支持链，标出实体 ID、关系、限定条件、来源和金答案。
2. 确定保持答案还是改变答案；保持答案的攻击不能再引入另一个满足全部条件的答案。
3. 选择攻击锚点、共享主体、假关系和同类型终点，先生成结构化假链，再生成文本。
4. 检查假链的每条边确有文本支持，同时证明至少一条边不符合原查询约束。
5. 在完整上下文重新求解，排除旁路、意外共指、同名别名及直接暴露答案的句子。
6. 记录假终点、分岔跳、无效原因及证据定位；保留原题—扰动题配对。
7. 以等段数和近似等长度对照分别隔离“攻击语义”与“上下文长度”影响。

重要补充：结构上完整的假链可以是事实完全真实的无关路径；真正捏造事实必须标记合成性质。无来源优先级的直接矛盾应归入冲突/歧义状态，不应继续沿用唯一金答案。相关作答规则见 [歧义与条件报告](04_歧义条件与时间场景.md)。
