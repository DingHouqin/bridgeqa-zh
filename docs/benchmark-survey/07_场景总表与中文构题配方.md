# 07｜场景总表与中文构题配方

[返回系列入口](README.md)。本报告是**跨研究归纳及项目候选设计**，不是任何论文的官方分类，也不是已验证的攻击集。

## 先分轴，再组合

建议每道题同时记录四组标签：基础操作（桥接、比较、集合、规则等）、扰动机制（换实体、改条件、插入噪声等）、证据环境（给定上下文、全文检索、表格等）、作答状态（唯一答案、多答案、歧义、冲突、证据不足）。同一道题可以对应多个场景；32 个单元不能相加为互斥样本数量。

下表“已有”表示来源直接覆盖相应机制，“迁移”表示来源任务需改造成中文多跳，“推演”表示基于来源提出的新组合或控制设计。具体方法与核验范围见 [资料目录](00_范围与资料目录.md) 和各专题，不能把迁移、推演写成原作者实验结论。

## 32 个候选场景单元

| ID / 场景 | 来源与归纳状态 | 问题如何设计 | 干扰及验收重点 |
|---|---|---|---|
| S01 串行桥接 | 已有：[HotpotQA](https://arxiv.org/abs/1809.09600)、[MuSiQue](https://aclanthology.org/2022.tacl-1.31/) | 先求实体 B，再问 B 的属性 C；后一步必须用到前一步答案。 | 删除或遮蔽桥接证据后应失去完整支持；排除直接泄露 C 的摘要。 |
| S02 并行比较 | 已有：[HotpotQA](https://arxiv.org/abs/1809.09600) | 分别提取 A、B 的同一属性，再比较大小、早晚或相等性。 | 保证单位与参照一致；仅见一侧证据不能完成比较。 |
| S03 关系组合推导 | 已有：[2Wiki](https://aclanthology.org/2020.coling-main.580/) | 根据两条关系和明确许可的组合规则，问新关系或端点。 | 不能默认所有关系都可传递；关系类型和方向均需验证。 |
| S04 桥接后比较 | 已有：[2Wiki](https://aclanthology.org/2020.coling-main.580/) | 两个起点各自桥接到对象，再比较对象属性。 | 最少两个桥接分支；禁止替换成比较起点属性。 |
| S05 集合筛选、合取与极值 | 已有：[ComplexWebQuestions](https://aclanthology.org/N18-1059/)；操作参考 [Break](https://arxiv.org/abs/2001.11770) | 先生成候选集合，再按交集、条件或最大值返回对象。 | 构造只满足部分约束的高相似候选；检验全部条件及全集是否充分。 |
| S06 扇出检索与聚合 | 已有：[FanOutQA](https://aclanthology.org/2024.acl-short.2/) | 先找完整成员集合，再逐成员查询，最后求和、列表或比较。 | 控制分支数；漏一个成员也应影响结果或集合召回。 |
| S07 检索后算术、常识或符号加工 | 已有：[MoreHopQA](https://arxiv.org/html/2406.13397v1) | 多跳取到实体或数值后，增加有明确规则的加工步骤。 | 诊断实体取错与后处理错；中文日期、字数、单位须另定规范。 |
| S08 大规模普通噪声 | 已有：[BABILong](https://github.com/booydar/babilong)、[LV-Eval](https://github.com/infinigence/LVEval) | 保留原问题与支持链，增添不改变答案的背景。 | 同时控制长度、相关度、来源；背景不能意外产生新答案。 |
| S09 共享实体的无关分支 | 已有：[CLUTRR](https://aclanthology.org/D19-1458/)；中文多跳迁移 | 目标链外插入只共享一个节点的关系或活动。 | 分支语义真实但不满足问题关系；检查模型是否跨到错误角色。 |
| S10 冗余有效路径 | 已有：[CLUTRR](https://aclanthology.org/D19-1458/)；一般 QA 迁移 | 为同一正确结论增加更长的合法路径或重复支持。 | 必须接受多条合法证据链；不把不同于标准链判错。 |
| S11 表面匹配的假答案 | 已有：[ADDDOC](https://aclanthology.org/P19-1262/) | 相似段落含错误候选答案，但从题目起点无法合法连接。 | 文本相似性与逻辑连接分开控制；不能制造无规则的直接事实冲突。 |
| S12 条件修饰改变的连续假链 | 已有：[Plausible Distractors](https://aclanthology.org/2024.emnlp-main.147/) | 把原题的年份、赛事阶段、角色等关键修饰改掉，再为改后的问题构造完整链。 | 假链自身可以连通，但不得满足原题条件；记录首次错配处。 |
| S13 同类型假桥接实体 | 已有：[CRiT-QA](https://aclanthology.org/2026.lrec-1.410/) | 在中间节点加入同类型候选及相关关系段落。 | 实体替换后仍像合理答案，但目标关系或上下文身份不匹配。 |
| S14 多锚点替代链 | 已有：[CRiT-QA](https://aclanthology.org/2026.lrec-1.410/) | 在多个跳位分别产生替代分支，增加诱导路径数量。 | 记录每条分支的偏离点；控制分支数量与总长度，避免只测文本增长。 |
| S15 反事实世界与记忆干扰 | 已有：[CofCA](https://arxiv.org/html/2402.11924v5)、[CRiT-QA](https://aclanthology.org/2026.lrec-1.410/) | 一致改写事实和下游实体，再按新世界构题。 | 明示按给定材料作答；同步改所有依赖，避免新旧两链同时有效。 |
| S16 证据位置与远距离链 | 已有：[BABILong](https://github.com/booydar/babilong)、[RULER](https://github.com/NVIDIA/RULER)；组合推演 | 固定支持事实，把各跳放在开头、中间、末尾或远隔位置。 | 答案保持、token 数匹配；截断导致缺证据应单独标记。 |
| S17 重复频率和段落顺序 | 推演；参考 [RULER](https://github.com/NVIDIA/RULER) 聚合任务与 [ADDDOC](https://aclanthology.org/P19-1262/) 位置操作 | 同一无关陈述重复出现，或只打乱段落顺序，查询仍依赖唯一合法链。 | 重复次数不是事实优先级；事实时序题需保留显式时间，否则重排会改题。 |
| S18 别名、指代与复合主语 | 迁移：[bAbI](https://github.com/facebookarchive/bAbI-tasks) 的指代/合取任务 | 将桥接节点写成别名、代词或并列人物，要求跨句消解后连接。 | 同名不同人有可核验区分；故意缺消歧信息时改标歧义。 |
| S19 合法逆关系与角色反转 | 迁移：[bAbI](https://github.com/facebookarchive/bAbI-tasks)、[CLUTRR](https://aclanthology.org/D19-1458/) | 从终点查询前驱，或把“甲赠给乙”改问受赠者的赠予者。 | 用合法逆关系，不能沿用同一关系名称；多前驱时返回集合。 |
| S20 正反方向成对访问 | 推演；研究动机参考 [Reversal Curse](https://arxiv.org/html/2309.12288v4) | 在相同给定事实下做正向与反向查询，匹配跳数与答案形式。 | 此处测上下文中的访问方向，不复现参数训练的 Reversal Curse。 |
| S21 无效逆推陷阱 | 迁移：[ProofWriter](https://aclanthology.org/2021.findings-acl.317/) | 只给 A→B 和 B 成立，再问 A 是否必然成立。 | 开放世界应判不确定；显式许可 B→A 后再建立可答对照。 |
| S22 受限溯因与缺失事实 | 已有：[ProofWriter](https://aclanthology.org/2021.findings-acl.317/)；多跳 QA 迁移 | 给规则与目标，问补哪条允许类型的事实可使目标得到证明。 | 输出所有允许的最小补充；不是断言这些事实已经为真。 |
| S23 否定、未知与量词 | 迁移：[bAbI](https://github.com/facebookarchive/bAbI-tasks)、[ProofWriter](https://aclanthology.org/2021.findings-acl.317/)；量词组合推演 | 让同一多跳命题分别处于可证真、可证假、未知；组合“所有/至少一个”等条件。 | 明确开放/封闭世界；“没找到”不能自动解释成“否定”。 |
| S24 时间区间与事件先后 | 已有：[Complex-TR](https://aclanthology.org/2024.findings-acl.374/)、[MultiHop-RAG](https://arxiv.org/html/2401.15391v1) | 先定位事件时间，再筛选重叠、包含、此前/此后的实体或事件。 | 边界是否闭合、时间粒度及同名事件必须规范；可能多答案。 |
| S25 时空语境改变答案 | 迁移：[SituatedQA](https://aclanthology.org/2021.emnlp-main.586.pdf) | 用相同主体问题配不同参考日期、地区，再接下一跳属性查询。 | 每一条件对应独立答案；不能把旧日期答案判成无条件错事实。 |
| S26 多解释歧义 | 迁移：[AmbigQA](https://aclanthology.org/2020.emnlp-main.466/)、[ASQA](https://aclanthology.org/2022.emnlp-main.566/) | 故意移除实体、事件、属性、类型或时间限定，使多条链均合法。 | 返回解释—答案映射或提出有效澄清；消歧版本作为对照。 |
| S27 条件层级与多跨度答案 | 迁移：[CMQA](https://aclanthology.org/2022.coling-1.146/) | 先确定上层条件，再取相应下层结论，答案可能多个片段。 | 保留条件与结论关系，不能只给扁平答案列表。 |
| S28 缺失桥接与不可作答 | 已有：[MuSiQue](https://aclanthology.org/2022.tacl-1.31/)；参考 [IIRC](https://aclanthology.org/2020.emnlp-main.86/) | 删除所有能支撑必需中间连接的证据，同时保留诱人末端候选。 | 检查替代合法路径也已删除；缺证据状态不能用常识猜答案。 |
| S29 错误预设与显式假设 | 迁移：[CREPE](https://aclanthology.org/2023.acl-long.583/)、[IfQA](https://aclanthology.org/2023.emnlp-main.515/) | 对比“并未获奖却问获奖后……”与“假设获奖，则……”；再加入后续条件。 | 错误事实前提应纠正；合法假设应按假设解题，两者标签不同。 |
| S30 知识更新沿链传播 | 已有：[MQuAKE](https://aclanthology.org/2023.emnlp-main.971/)；参考 [RippleEdits](https://aclanthology.org/2024.tacl-1.16/) | 改一条桥接事实，再问更新后受影响的终点及不受影响的控制问题。 | 明确更新时间/覆盖规则；旧事实不失效则可能是时间题或冲突题。 |
| S31 新旧、流行与长尾混合链 | 已有：[MINTQA](https://aclanthology.org/2026.acl-long.18/) | 按快照新增和流行度分层选链，控制新/尾知识所在跳位。 | 新增记录不等于新近发生；给定证据与自主检索分别测试。 |
| S32 表格—文本与跨模态连接 | 已有：[HybridQA](https://aclanthology.org/2020.findings-emnlp.91/)、[MultiModalQA](https://arxiv.org/abs/2104.06039) | 先由行/列或图像标识找实体，再连接文本属性并返回结果。 | 表格单位、行键、实体身份可验证；视觉扩展仍只是候选范围。 |

## 对用户所列五类场景的对应

| 关注的现象 | 对应单元 | 必须区分的子情况 |
|---|---|---|
| 大规模干扰、冗余文本 | S08–S10、S16–S17 | 随机背景、语义相关分支、合法冗余支持、位置远隔和频率偏置不同。 |
| 虚假中间线索 | S11–S14、S18 | 断开的假答案、改条件的连续假链、同类型假桥、多跳分岔、错误指代。 |
| 误导性关联信息 | S09、S12–S14、S18–S19、S30 | 共享实体不等于共享关系；角色、时间和更新状态都可能错配。 |
| 歧义提问 | S25–S29 | 多种合法解释、条件未指定、桥接缺失、错误预设分别对应不同作答状态。 |
| 反向推理 | S19–S22 | 合法逆关系、反向访问、无效逆推、溯因补充的规则不同。 |

范围之外仍可能有其他机制；这张表是构建和审查的工作清单，不是已经冻结的项目分类。

## 横跨场景的协议有效性诊断

按用户指定的 [多跳A组 AI构造分析](thread://01a113c1-16a5-77e0-b5dc-75136a5a14ff?hostId=local) 恢复以下构造。它们可作用于多个 S 编号，不追加为互斥场景，也不是已完成的样本：

| 诊断构造 | 构题和预期响应 | 要排查的问题 |
|---|---|---|
| 必要/无关/替代支持删除 | 删除所有必要事实支持应不足；删无关内容或一条可替代参考边仍可答。 | 固定缺失标记泄露状态，或把参考句误当成必要事实。 |
| 同材料切换问题起点 | 保持材料，仅换同类型起点；按目标链重新给答案与证明。 | 不读问题、只扫描汇合节点或显眼终点。 |
| 同答案、不同合法证明 | 不同起点到达同一终点，问句要求各自起点的依据。 | 答案始终相同掩盖证明错误。 |
| 分布式重复支持 | 同事实多个表述，删一处保持；删全部支持才不足。 | 句级删证不足以判断事实级充分性。 |
| 表面不变性与语义变化 | 重排/等价改写应保持；合法关系改接应更新；代号按映射。 | 模型对文风、位置或命名敏感，而非目标关系变化。 |
| 控制图结构的内部桥改接 | 在临时世界中比较单边改接与保度数双边交换，再查全图真值。 | 特殊入度、终点角色或其他拓扑线索泄露新答案。 |

这些构造如何进入多步骤评分、跨条件成功与历史反例审查，见 [核心评判与创新点回收](09_多步骤评判与核心创新点回收.md)。

## 七个中文构题配方

以下全部为原创封闭世界示例。每个示例先确定合法链，再产生干扰，最后验证题目状态。它们解释构造方法，不是已采集样本，也没有声称任何模型已经被诱导。

### 配方 A：普通噪声、相关噪声与合法冗余分别扩增

核心事实：“《潮声》的作者是林澄。”“林澄受雇于远帆社。”“远帆社总部在望江市。”

问题：“《潮声》作者受雇机构的总部位于哪座城市？”答案为望江市；链为作品→作者→雇主→总部。

普通噪声可加入其他作品、交通、活动段落；相关噪声可加入“林澄为晨舟社提供顾问服务，晨舟社总部在星湖市”；合法冗余可改写同一雇佣事实，或补一条独立支持同一结论的路径。可能诱人错误是星湖市。相关分支是真实的示例事实，但“顾问服务”不能替代“受雇”。

验收：背景不能新增其他作者或雇主；每个长度档都保留所有支持；普通/相关两组匹配长度；合法冗余须加入可接受证据集合。设计参考 [长文本专题](03_长上下文与大规模干扰.md) 与 [对抗专题](02_冗余替代链与反事实陷阱.md)。

### 配方 B：保留表面主题，制造条件不匹配的双段假链

核心事实：“星岸队常规赛主场是北湾馆。”“北湾馆容量为 4,000 人。”

另加入：“星岸队季后赛主场是南峰馆。”“南峰馆容量为 4,500 人。”

问题：“星岸队常规赛主场可容纳多少人？”正确链为星岸队→常规赛主场→北湾馆→4,000，诱人假链为星岸队→季后赛主场→南峰馆→4,500。

验收：同赛季和同容量定义；两种赛事条件在问题、证据、结构标签中一致；原问题不能被假链满足。可把条件换成年份、正式/代理职位、母公司/子公司，但每次只改变有明确定义的维度。方法动机来自 [Plausible Distractors](https://aclanthology.org/2024.emnlp-main.147/)，这里的队名、场馆和数值是自拟。

### 配方 C：角色关联与中间实体身份错配

事实：“《潮声》作者是林澄，编辑是周禾。”“周禾受雇于晨舟社。”“晨舟社总部在星湖市。”仍保留配方 A 的作者链。

询问作者雇主的总部，错误链可从作品跳到编辑，再沿真实的雇佣和总部关系返回星湖市。进一步加入同名“林澄（运动员）”及其机构信息，构造身份错配。

验收：每条关系本身无矛盾；错误出在问题要求的角色或实体标识。名字相同时材料必须能消歧；若问题未说明身份且两种解释都合法，应按配方 D 重标，不能强行认定假桥。图结构噪声与身份问题参考 [CLUTRR](https://aclanthology.org/D19-1458/) 和 [歧义专题](04_歧义条件与时间场景.md)。

### 配方 D：让歧义成为合法任务状态

事实：“《潮声》（小说）的作者林澄受雇于远帆社，总部望江市。”“《潮声》（戏剧）的作者江晓受雇于晨舟社，总部星湖市。”

含糊问题：“《潮声》作者工作的机构总部在哪里？”合理输出是“若指小说，则望江市；若指戏剧，则星湖市”，或者询问“指小说还是戏剧？”

对照问题加入“小说”限定，恢复唯一答案望江市。可分别扩展事件版本、时期、属性口径和答案类型；这些维度不是必须互斥。

验收：每个解释有独立完整证据链，澄清后确实缩小答案空间；“有多个集合成员”与“有多个题意”分开标。构题依据参考 [AmbigQA](https://aclanthology.org/2020.emnlp-main.466/)；多跳延伸为本项目候选。

### 配方 E：合法反查和错误逆推成对设计

合法反查材料：“林澄受雇于远帆社。”“江晓受雇于远帆社。”“《潮声》作者是林澄。”问题：“远帆社雇员中谁是《潮声》的作者？”先求雇员集合，再交叉筛选，答案林澄。不能把“远帆社受雇于林澄”当作逆向表述。

错误逆推材料：“凡在远帆社受雇的人都有蓝色通行证。”“林澄有蓝色通行证。”问“林澄一定受雇于远帆社吗？”按开放世界规则回答不确定，因为没有给“蓝证→受雇”。

对照可增加逆向规则，或明确补充事实后再问；溯因版本可问“增加哪条允许的事实能证明林澄受雇”，但不能把假设补充当成已知事实。验收需区分关系反查、逻辑蕴含和溯因。详细区分见 [反向专题](05_反向规则与知识更新.md)。

### 配方 F：时间更新造成旧链诱导

事实：“至 2024 年末，林澄受雇于远帆社。”“自 2025 年 1 月起，林澄离开远帆社，受雇于晨舟社。”“两社总部分别为望江市、星湖市。”

问题分别指定 2024 年 6 月和 2025 年 6 月。答案分别为望江市、星湖市。可加入旧网页摘要、发布日期与事件日期不一致的段落，诱导忽视查询时间。

验收：先固定区间边界，保证是否兼职已说明；发布日期不能自动当成任职起始日。如果把它改造成显式反事实编辑，则要写清“新记录替代旧雇佣关系”的规则，并把新答案用作 gold，而非计算答案保持型攻击成功率。参考 [Complex-TR](https://aclanthology.org/2024.findings-acl.374/) 和 [MQuAKE](https://aclanthology.org/2023.emnlp-main.971/)。

### 配方 G：条件层级、表格连接与聚合

表格列出三家出版社及总部代码；另两段说明代码对应城市与城市所在地区。政策段落：“东部地区出版机构的首版图书申请 A 类补助；其他地区申请 B 类；再版图书均申请 C 类。”

问题：“远帆社在 2025 年出版的首版《潮声》应申请哪类补助？”需完成出版社行定位→总部代码→城市→地区→政策条件分支。再版、其他机构和过期政策是合法干扰。可扩展成“所有符合 A 类条件的作品各有多少印量，总量是多少”，增加扇出聚合。

验收：机构键唯一、代码映射有效、政策适用时间明确；条件分支有覆盖范围，数量单位一致。条件机制参考 [CMQA](https://aclanthology.org/2022.coling-1.146/)，表格连接参考 [HybridQA](https://aclanthology.org/2020.findings-emnlp.91/)，组合为候选。

## 大规模生成时需要保存的构造记录

建议记录基础题 ID、变体 ID、来源与定位链接、世界版本、问句、证据段/句 ID、实体身份、关系方向、约束、全部合法答案和证明、错误候选链、扰动算子、强度、种子、生成与审核版本、作答状态及人工审查结论。字段是设计建议，正式 schema 尚未冻结。

同一基础题可生成多个控制变体：原始、随机噪声、相关噪声、条件假链、实体假桥、位置变体。先单因素再组合；答案改变、歧义化、删桥分别建立独立任务族。实体替换要沿下游传播，条件替换要与假链一致，改问句要同步检查 gold。

规模来自可控的证据图、问题模板、语言改写和扰动参数组合，不应来自无审查地让模型重复编造。进入大规模生成前，用独立审查确认多跳依赖、题目状态、来源可追溯性与真实难度；相关门槛和指标见 [评测与迁移报告](08_评测指标与项目迁移.md)。
