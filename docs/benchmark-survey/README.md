# 多跳问答与对抗 benchmark 系列调研

调研日期：**2026-10-07（Asia/Shanghai）**。本系列回答两个问题：已有基准覆盖了哪些场景，以及这些场景的题目、证据和干扰究竟如何构造。研究范围包含经典多跳 QA、直接对抗评测，以及可迁移的长上下文、歧义、规则推理与知识更新诊断。

当前整理 **42 项基准、基准套件或诊断研究**，包括本次按用户要求补回的 [DAComp](https://arxiv.org/abs/2512.04324)。其中部分是辅助研究，不能全部称为严格的跨文档多跳 benchmark；套件、衍生版本与数据集可能共享样本，不能相加为独立数据规模。收录依据是已发表、经典使用或与目标机制直接相关且有公开一手材料，不按未经核验的引用量排名，也不声称穷尽所有论文。

**核心方向补充**：从 [多跳A组 AI构造分析](thread://01a113c1-16a5-77e0-b5dc-75136a5a14ff?hostId=local) 恢复多步骤分层评判与协议有效性主线，优先读 [09：多步骤评判与核心创新点回收](09_多步骤评判与核心创新点回收.md)。它涉及评判协议和跨条件诊断，不作为第 33 个互斥场景硬塞入分类。

## 如何理解报告里的结论

- **原文事实**：论文、作者仓库或官方数据页直接支持的构造和设置，附近附有可跳转链接。
- **本调研归纳**：跨研究统一整理的分析维度。例如 32 个场景单元不是任何一篇论文的官方分类。
- **本项目候选**：为中文任务给出的原创示意、构造配方和指标建议，尚未成为最终方案，也未经过实测。

所有中文小例子默认是为解释机制编写的合成示例，**不是现成数据集的原题翻译，也不是已采集的现实事实**。例子中的数字、角色和机构仅在该示例的封闭世界中成立。
