# 04｜歧义、条件、时空限定与不可作答

[返回入口](README.md) · [资料目录](00_范围与资料目录.md)。本报告中的中文问题为原创示意。

## 1. AmbigQA：六类歧义观察与消歧题

[AmbigQA 方法与 Table 1](https://aclanthology.org/2020.emnlp-main.466.pdf) 让标注者为 NQ-open 问题搜索合理答案，为不同答案编写消歧后的问题。发布的 AmbigNQ 有 14,042 条标注。Table 1 从 100 条开发样本观察出六类歧义，允许一题属于多类；它不是互斥且穷尽的正式逻辑分类。

| 原文观察类型 | 中文示意 | 设计时应保存什么 |
|---|---|---|
| event references | 某人“成婚”指举行仪式还是登记？ | 每种事件定义对应的证据与答案。 |
| properties | 某剧有几集，是否包含特别篇？ | 计数口径与纳入条件。 |
| entity references | “林澄”指同名作者还是画家？ | 稳定实体 ID 与区分信息。 |
| answer types | 问“谁演唱”是乐队还是主唱？ | 答案类型与对应关系。 |
| time dependency | “最新一季”以哪个时间点为准？ | 时间锚及当时状态。 |
| multiple sub-questions | “作者和编辑是谁”需要分别回答两角色。 | 子问题—答案映射。 |

**多跳迁移示意。** 上下文同时存在“作者林澄→远帆社→望江市”和“画家林澄→星桥社→东浦市”；问题“林澄所在机构总部在哪？”缺少职业限定。这时 {望江市、东浦市} 均可能成立，不能指定一个答案并把另一个当作陷阱命中。可配对生成“作者林澄……”的明确版本，测试模型是否识别新增限定。

## 2. ASQA：同时解释多种答案

[ASQA 原论文](https://aclanthology.org/2022.emnlp-main.566/) 在歧义 factoid 问题上要求能解释不同解释的长回答。其可迁移点是评价解释与答案覆盖，而不是只对单个字符串做 EM。它不保证每个解释都需要多跳，也不能把所有多答案集合问答称作歧义。

**本项目候选。** 对同名实体题，允许列出各解释及答案；若采用交互模式，可先问“你指作者还是画家？”再在澄清后作答。列举所有解释与主动澄清是两种不同评测协议，必须先确定哪一种算正确。

## 3. CMQA：中文条件分支与层级多跨度

[CMQA 构建 §3](https://aclanthology.org/2022.coling-1.146.pdf) 从社区问答筛选无法用一个跨度回答的中文样本，标注条件、答案跨度及层级关系，经标注培训和一致性检查后得到 7,861 条。它刻画条件与层次，并不以多文档多跳为必要条件。

**候选示意。** 活动规则：本校学生凭学生证免费；校外学生凭预约码五折；无预约码原价。个人资料散在另一段。问“方宁参加活动需要支付原价吗？”应先查是否本校、是否有预约，再匹配规则。假线索可以把“学生”泛化为“所有学生免费”，但必须保留原规则中的限定。

**验收。** 标注条件—答案配对，并说明规则是否穷尽。仅知道方宁是学生但不知道学校或预约状态时，应给条件式答案或请求补充；不能强制选择某一分支。

## 4. SituatedQA 与 Complex-TR：时间不仅是日期排序

[SituatedQA](https://aclanthology.org/2021.emnlp-main.586.pdf) 研究同一问题在不同时间或地理语境下如何有不同答案。可迁移操作是为同一题显式附加时间/地点，不能把随语境变化的答案称作标注不一致。

[Complex-TR §2](https://aclanthology.org/2024.findings-acl.374.pdf) 从带起止时间限定的 Wikidata 事实构造题，重点覆盖 time-event（L2）与 event-event（L3），以及多跳、多答案；作者的 hop 口径涉及必要时间点/区间推理，未必等于文档数量。集合准确率及答案 F1 用于处理多答案。

**区间示意。** 方宁在 2018–2020 年任职于明川馆；获奖记录为 2019 年甲奖、2021 年乙奖。问“任职明川馆期间获得哪些奖？”要取任职区间并筛选奖项，答案 {甲奖}。干扰可放在同一个人的另一个任职阶段，或用 2021 年的更新摘要诱导忽略旧区间。

**更困难的候选。** 两职位区间重叠、事件发生时点与发表时点不同、只有年份而问题要求月份、区间端点开闭不同。它们是由上述机制推演的候选，不代表每种都已被原数据独立覆盖。遇到信息粒度不足，标为未知或范围，不能凭假精度作答。

## 5. IIRC 与 MuSiQue-Full：不同原因的无答案

[IIRC 原论文](https://aclanthology.org/2020.emnlp-main.86/) 让人根据起始段落写题，但不看链接文档；后续信息可能藏在链接中，也可能不存在。任务区分发现缺信息、寻找信息与回答。[MuSiQue-Full 方法](https://aclanthology.org/2022.tacl-1.31.pdf) 增加不可作答的对照问题，用于检验完整依赖链。

**本调研归纳。** 至少区分：给定上下文缺证据、检索未找到已存在的证据、语料本身无答案、问题有多个合法解释、证据互相冲突。前三者的处置取决于是否允许工具检索，后两者需要另设作答协议。

**示意。** 问《潮声》作者任职机构的总部，提供作品→作者与组织→总部，却删去作者→任职组织。题目可能仍有城市词，但链不完整。验收应枚举完整上下文中的替代路径，确保缺失边无法从别处恢复。

## 6. IfQA 与 CREPE：显式假设和错误预设必须分开

[IfQA](https://aclanthology.org/2023.emnlp-main.515/) 在问题中写明 if 条件，要求结合反事实前提与检索事实回答。[CREPE](https://aclanthology.org/2023.acl-long.583/) 面对真实信息寻求中的错误预设，标注预设是否错误及如何纠正。它们是相邻 QA 研究，不能宣称所有题都是多跳。

**两个不同任务。**

- 明示“在架空规则下，明川馆不属于本校；方宁是本校学生，哪些场馆可免票？”这是接受任务设定后推理。
- 问“方宁再次获得甲奖是哪一年？”但证据表明只获奖一次，且任务要求核验事实。这是识别“再次”的错误预设，应指出前提未被支持。

把架空世界的假设当作错误预设拒绝，或把错误预设当成合法 if 条件接受，都会产生错误评测。指令必须写明是“按给定世界回答”还是“核实现实事实”。

## 7. 作答状态与标签候选

建议保存：唯一答案、集合答案（题意明确但对象多个）、多解释答案、信息不足、证据冲突、错误预设。每种状态应有对应评分规则。例如集合题漏掉一个成员应降低召回，歧义题擅自单选应降低解释覆盖，缺信息题的合理拒答应算对。具体指标候选见 [评测报告](08_评测指标与项目迁移.md)。
