# 风险与待定事项

| 问题 | 对结果的影响 | 下一步 |
|---|---|---|
| 主次领域未选 | 来源与关系分布不稳定 | 各领域小批 pilot 后选择 |
| 3/4 跳自然性与唯一性 | 长题可能只是坏题 | 删证据审核、替代路径和人类答题 |
| 隐藏英语原题公开 | 记忆污染 | translated 单列参照，native 支撑主结论 |
| 中文原生种子仍可能被预训练见过 | 不能保证完全新知识 | 来源/日期、记忆诊断与证据约束说明 |
| 对抗直接矛盾 | 无法判断哪个事实可信 | 使用非蕴涵真实负例，冲突单独协议 |
| 语言安排与英文数量/边界共变 | 无法称纯切换位置效应 | 完整/平衡排列或收窄主张 |
| 模型输出自由路径 | 与内部机制不等价 | support/steps 对照与 prefix 干预 |
| 各种因素全组合 | 小格子样本不足 | 固定主比较，其余记录协变量 |
| 来源许可与数据发布 | 不能默认统一授权 | 逐来源记录、发布前核查 |
| 课程闭源限制的辅助工具解释 | AI 使用范围未确认 | 启动时向教师确认，正式流水线保守合规 |
| 演示/报告版本不一致 | 课程扣分风险 | 冻结清单、缓存标签与差异说明 |

待填：成员姓名、B 组联系人、GPU、模型许可与参数、真实展示日期、训练授权、领域、预算、数据规模、统计主比较、最终数据发布方式。
