# 数据构建流程

`来源冻结 → 候选事实 → 证据图 → 中文问题 → 必要性检查 → 分组切分 → 对照/攻击 → 自动检查 → 独立人工审核 → 冻结 → 评测`。

## 每一步的输入与输出

| 步骤 | 输入 | 输出 | 主要复核 |
|---|---|---|---|
| 采集 | 许可可核对的中文来源或英文 benchmark | 原文件、URL、日期、版本、哈希 | 来源事实与分发条件 |
| 标准化 | 原段落与元数据 | 稳定 doc_id / sentence_id / entity_id | 分句不改变关系、否定和限定词 |
| 建图 | 有来源句的事实关系 | 2–4 跳依赖图与备选路径 | 关系与时间范围一致 |
| 写题 | 证据图 | 中文自然问题、答案类型、别名 | 唯一性、自然性、无答案泄漏 |
| 查捷径 | 问题与证据包 | 单跳/删证据检查记录 | 单文档、类型线索和未标注替代路径 |
| 切分 | 种子与关系簇 | split manifest | 共享组件与近重复审查 |
| 造攻击 | seed 与指定 attack spec | gold_only / control / adversarial | 一次主要改动，预期 decoy 路径 |
| 双语 | 已审核中文种子 | 证据等义译文与语言排列 | 原义、别名、句 ID 与输出答案 |
| QC | 候选与自动结果 | approved / revise / reject | 独立审核与争议裁决 |
| 冻结 | 批准数据 | 输入/标签分离、版本与哈希 | 隐藏信息未泄漏 |

规则、真实语料 hard-negative、允许的本地开源生成器逐级引入。规则保证可解释的转换，检索保证自然负例，本地生成只补语言表达；三者最终都需要复核，不预设固定配比。

自动检查覆盖字段/ID、路径连续性、证据存在、配对 gold 一致、split、重复、长度及明显答案泄漏。字符串“不含答案”不是完整的泄漏证明；图搜索找不到其他路径也不是唯一性的证明。

每次生成保存 source_method、generator_revision、prompt_version、rng_seed 和修改位置。机器提案与 final gold 分目录保存；被拒绝候选保留理由，用于统计构建失败原因。
