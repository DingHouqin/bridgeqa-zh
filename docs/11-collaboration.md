# 四人协作

以下 A1–A4 是组内角色，不是对抗 B 组。所有人承担一定审核量，展示和报告共同署名。

| 角色 | 姓名/时间待填 | 主责 | 交叉责任 |
|---|---|---|---|
| A1 协议与统筹 | | schema、切分、A/B 协议、决策记录 | 报告、隐藏集版本 |
| A2 数据与生成 | | 采集/loader、规则和 hard-negative | 自动校验、来源与许可 |
| A3 标注与双语 | | 标注手册、双语审核、歧义/反向题 | 争议裁决、质量统计 |
| A4 实验与展示 | | baseline runner、评分、缓存/演示 | 统计图、复现、逐跳诊断 |

分工不是独占目录；每个模块至少一名负责人、一名复核者。生成者不能批准自己的 gold；双语审核安排具备相应语言能力的第二人。

每周记录本周完成、阻碍、下周可验收项；以可追溯产出和实际耗时调整取样规模。重要口径修改在 decisions 表登记。

建议分支工作，每次数据批次提交公开摘要与审核报告；隐藏材料通过授权的私有渠道共享。主分支保留可运行 fixture 和对应协议。详见 CONTRIBUTING.md 与 PR 模板。
