# 课程要求与交付对应

依据 `references/course/PJ要求2026.docx` 和 `references/course/AB对抗组选题说明.docx`。与原件冲突时以原件和教师解释为准。

| 课程说明 | 项目对应 | 最终证据 |
|---|---|---|
| 四人以内，第 3 周周末提交名单与题目 | collaboration / decisions | 名单与选题提交记录 |
| A 组设计任务、数据与评测指标 | scope / taxonomy / evaluation | 规范、样本、代码与结果 |
| 多跳五类：冗余、假中间线索、误导关联、歧义、反向 | attack taxonomy 的 context/query 两 track | 各类统计与可回答性审核 |
| 数据来源、流程、样本思路、陷阱、标注、困难统计 | data strategy / pipeline / annotation / reports | source manifest、审核记录、分布与失败分析 |
| 比较普通和对抗性能、分析认知缺陷与优化方向 | matched pairs / stepwise / A-B | 冻结模型的主表与案例 |
| 期中设计/框架/采集/当前进度 | midpoint outline | 可运行闭环与真实初步数据 |
| 期末展示完成成果 | final demo | 固定版本、缓存/实时说明 |
| 报告正文 <=8 页，参考文献附件另算 | final outline | 实际分页检查与分工说明 |
| AI/模型/前人成果详细说明；闭源大模型禁令；开源 <30B | AGENTS / model config / AI 表 | 许可、参数、revision、提示、用途与审核 |
| 演示/报告不一致须解释 | manifest / demo checklist | 同一运行或有记录的差异 |
| 第 18 周周五 24 点前提交 zip/tar | reports/submission-checklist.md | 报告、全部代码、自建数据与资料 |
| 逾期每日扣项目成绩 10% | roadmap | 实际提交时间 |

评分：期中 30、期末 40、交付材料 30；两次展示中同学/教师（含助教）各占 50%。此表不承诺分数，不以数据数量替代质量。

## 项目贡献对应的展示证据

详细定位见 [项目意义与贡献](18-purpose-and-contributions.md)，验收见 [贡献验证计划](../experiments/plans/contribution-validation.md)。以下用于组织成果，不是教师额外公布的评分细则。

| 项目贡献 | 课程要求的对应材料 | 展示/交付证据 |
|---|---|---|
| C1 中文来源与必要链 | 数据来源、流程、标注、困难统计 | 真实来源、事实图、限定、审核/拒绝记录与实际分布 |
| C2 严格配对攻击 | 陷阱/干扰构造、普通与对抗比较 | 配对不变量、语义核验、文本差异与冻结结果 |
| C3 分层与独立诊断 | 评测指标、失败与优化分析、A/B 合作 | 已实现评分、真实案例、独立上游诊断及 B0/B1 比较 |
| C4 构题流程质量/成本（可选） | 构建算法与过程说明 | 同事实包对照、实际人工/模型成本；不替代核心任务 |

课程可能训练完整的问题定义、评测、优化、实验和协作能力，这是根据要求的推断。成员工作、AI 使用、可复现材料及实际完成状态均应据实披露；不能保证特定分数。

命名：`第XX小组-项目期末报告`、`第XX小组-项目源代码`。XX、日期与渠道待教师通知。隐藏标签与完整实验可放私有课程包，避免公开仓库泄漏又遗漏课程交付。
