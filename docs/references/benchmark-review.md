# Benchmark 构造与本项目增量

此表是选题索引；不将“多篇文档”自动解释为“多跳”，不以不同数据集成绩直接比较语言能力。正式报告需阅读原论文的任务、来源和构建细节。

| 数据/工作 | 构造或任务特征 | 可借鉴 | 本项目要控制的缺口 |
|---|---|---|---|
| [HotpotQA](https://aclanthology.org/D18-1259/) | Wikipedia 上人工编写的桥接/比较题，提供支持句 | 中文翻译起步、证据粒度与干扰候选 | 原英文题可能被模型记忆；翻译不能当原生中文创新 |
| [2WikiMultiHopQA](https://aclanthology.org/2020.coling-main.580/) | 知识图谱与百科文本结合，按关系/推理模式构题 | 实体关系图、可审计路径、关系类型覆盖 | 模板语言捷径、图与文本一致性、真实跨文档必要性 |
| [MuSiQue](https://aclanthology.org/2022.tacl-1.31/) | 将单跳问题组合成连接的二至四跳题，过滤可绕过连接的题 | 2/3/4 跳种子、子问题与必要性检查 | 段落/分解标注不能未经审核当句级 gold；共享组件需同 split |

| [GRADE](https://aclanthology.org/2025.findings-emnlp.236/) | 多跳评测中的结构/语义难度相关研究 | 跳数之外记录语义距离与关系 | 增加跳数本身不是充分创新 |
| [XHotpotQA](https://arxiv.org/abs/2608.27481) | 基于英文 HotpotQA 的多语言/混合证据版本（2026 年预印本） | 同图跨语言条件、翻译审核 | 与已有混合证据任务区分：原生中文来源、严格攻击对、语言次数混杂 |
| [CLC-QuAD](https://arxiv.org/abs/2111.06086) | 中文复杂知识库问答，源自 LC-QuAD 2.0 的翻译路线 | 中文问题与结构化查询参照 | 知识库查询与文本证据问答需区分；中文题不一定来自中文原生证据 |
| [CCMOR](https://arxiv.org/abs/2510.08800) | 中文多跳事实链相关构造研究 | 原生中文事实链、审核与推理粒度 | 数据可下载状态须核查，不能仅据论文发布意向假定已经获取 |
| [BrowseComp-ZH](https://arxiv.org/abs/2504.19314) | 中文网络检索困难问题 | 中文信息分散、搜索成本的选题参考 | 搜索困难不必然对应已标注的必要事实跳数 |
| [MARCH](https://aclanthology.org/2026.findings-acl.1352/) / [RoMQA](https://aclanthology.org/2023.findings-emnlp.470/) | 歧义/约束与鲁棒性相关问答 | 歧义轨道、任务边界 | 歧义题 gold 可能为集合/澄清，不能并入单答案配对攻击 |

## 中文报告中的补充候选

原报告另涉及 NLPCC-MH、CHEF、CFEVER、ChronoQA、M4IVQA、MSLR、MedFact 等。它们的文本/知识图谱/核验任务、中文形态、许可、跳数定义与实际下载状态需逐一核验；目前未选入正式数据。事实核验可以借鉴证据组合，但不是直接等同本项目的多跳 QA。

- [NLPCC-MH 仓库线索](https://github.com/wavewangyue/NLPCC-MH)
- [CFEVER 项目](https://ikmlab.github.io/CFEVER/) 与 [数据仓库](https://github.com/IKMLab/CFEVER-data)

## 创新应落到可检验的增量

1. **原生中文证据与可审计必要链**：减少仅测翻译英语题的代表性问题。比较原生/翻译来源，记录语言与事实来源，价值是解释中文场景中的证据桥接。
2. **攻击的严格普通对照**：保持题目、gold、正确证据、数量/位置/长度预算，用错误角色或关系制造诱导路径。价值是让下降更能归因于干扰机制，而非上下文长度变化。
3. **同图跨语言证据与攻击交互**：中文题固定，在每个语言条件内配对，再比较图中不同跳的语言配置。价值是定位跨语言实体桥接和干扰传播；初始四条件不能识别全部独立因素。
4. **跳数、目标跳与可观察步骤诊断**：二三四跳支持难度曲线，三跳提供首/中/末位置；结合证据和步骤而非只给最终分数。价值是给 B 组可行动的优化线索。
5. **有效性、人工成本与跨域复核**：测审核成本、错误标注、捷径和次领域迁移。价值是可信、可复用的数据构建流程，而不是靠挑出模型失败题追求大 drop。

这是组合式实验设计的项目价值；新颖性强度须通过相关工作逐项对照，不宣称这些因素分别从未被研究。
