# 因素与实验预算

P0 主因素为 attack_type、target_hop、hop_count、证据语言排列。origin/domain 必须分层报告。记录长度、数量、顺序、答案类型、时间范围、来源和模型截断，避免把构成差异解释为机制。

P1 研究中英译名/缩写/同名实体、干扰语言、固定检索 Recall@k。P2 才做语义距离、图拓扑、时间限定、来源冲突与组合攻击。

## 推荐实验矩阵

1. 中文主集：三类 context attack，以三跳为主，分 target_hop 报告；歧义与反向独立题型。
2. 双语子集：复用同一批 native_zh 三跳 seeds，先 ZZZ/EZZ/ZEZ/ZZE；每种有 control/adv；只采用已经审核的一类主要机制，避免全攻击交叉。
3. 更严格语言分析：有资源时对同一子集补齐 8 排列，预定义比较，不把所有派生因子同时当独立变量。
4. 逐跳诊断：从实际失败例预定抽样，运行 gold-prefix 干预，与主结果分开。

例：60 seeds × 4 排列 × 2 上下文 = 480 records/模型，但独立样本仍只有 60。双语扩增复用图和译文，仍需审核攻击译文；不能按 480 算 CI。该规模为容量例子，未承诺已构建。

增加领域、hop、attack、语言、alias、长度的全组合会迅速形成小样本格子。优先回答已定义主问题，不以切片数量展示深度。
