# 中英证据实验

问题与回答语言首先固定为中文；事实图和规范答案在语言变体间不变。语料语言、种子 origin、翻译生成方式与答案语言分别记录。

## 两个来源设置

- controlled_parallel：从经过审核的 native_zh 种子制作等义英文证据，测给定文本中的语言因素。
- authentic_complementary：分别采集原生中文和英文页面，各提供必要的一跳；排查同语重复证据与常识捷径。作为现实性扩展，不能与平行译文的差异混算因果效应。

英文 benchmark 译成中文可作 external_reference；其 seed origin 不因流畅翻译变成 native_zh。

## 三跳条件

用 Z/E 表示中文/英文证据，问题固定 Z。

| 排列 | 初始子实验用途 | 边界数 |
|---|---|---:|
| ZZZ | 中文对照 | 0 |
| EZZ | 英文证据在首跳 | 1 |
| ZEZ | 英文证据在中跳 | 2 |
| ZZE | 英文证据在末跳 | 1 |

这四种条件只能直接描述英文证据角色位置的表现差异，ZEZ 同时改变切换次数。若要更严格估计顺序、方向与边界效应，在小子集补 ZEE、EEZ、EZE、EEE。三个语言位是基础处理变量，English 数量和 switch_count 是由排列决定的派生量，不应在完全共线模型里独立估计所有效应。

二跳可用 ZZ/ZE/EZ/EE，四跳不默认做全部 16 排列。不要把语言版本数当独立种子数。

## 配对与控制

每种排列都有自己的 control/adv，主要测同条件内攻击下降。再比较不同排列的下降差，如 `drop(ZEZ) - drop(ZZZ)`，这是交互对比，不自动证明某个内部机制。

攻击逻辑、target_hop、文档顺序、数量和上下文预算相同；文档 token 长度难以精确等同，记录所有模型 tokenizer 下的预算和截断，避免 gold 被截去。

实体 ID 和句 ID 稳定，保存中文/英文别名。新译名可能本身造成实体对齐难度，必须审核；评分采用规范实体/日期值与单独的输出语言检查。

双语质检记录关系等义、时间/否定/数值、实体对应、答案别名和语言标识。不用回译分数证明事实等义。干扰语言作为 P1 因素，先不与全部攻击交叉。
