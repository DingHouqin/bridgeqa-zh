# 项目范围

项目暂定题目为《面向原生中文与中英混合证据的多跳问答对抗评测》。四人以内 A 组构建 benchmark、生成算法和评测协议，与 B 组分析认知脆弱性。

核心研究问题：在问题、gold 与语义目标有效时，错误候选路径怎样导致模型选错中间实体或关系？这种作用是否受跳数、攻击目标跳和证据语言安排影响？领域泛化是补充问题。

## 任务定义

输入为问题与固定候选文本包，输出为答案、支持句 ID 和可选逐跳结构。P0 先测给定候选中的证据选择与组合；P1 再测固定语料检索，不把两者混算。

一跳是一条有证据支持且求解需要的事实关系。三跳为 `A → B → C → Y` 的三条边，不等于三篇文档。主集使用连接链，少量比较或交集图单独标 topology，分别保存 depth 与必要边数；不能用文档数代替 hop_count。

## 研究范围与验收

- P0：中文主集、2–4 跳、单因素 context attack、人工审核、公开开发和隐藏评测、普通/对抗比较。
- P0：覆盖课程的冗余、虚假中间线索、误导关联、歧义提问、反向推理；后两类单独定义标签与指标。
- P1：中文原生种子的受控中英证据子集、首个提交错误位置、gold-prefix 干预、固定语料检索。
- P2：自然双语互补、组合攻击、来源冲突、时间版本挑战和更复杂拓扑。

没有真实实验时不得写攻击“已经有效”。低模型成绩、显著下降和任何具体 ASR 均是观察结果，不是 gold 有效性的验收条件。

## 交付状态

当前是方案与最小工具；实际数据与实验待完成。新增工作先确认优先级和预算，避免把主集、八种语言排列、全部攻击和三种跳数作无预算的全组合。v0.1 样本 Schema 与参考工具仅支持单答案链式 context_attack；其他拓扑和挑战集须先扩展协议。
