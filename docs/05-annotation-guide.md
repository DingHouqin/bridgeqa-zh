# 标注手册 v0.1

本规范为试运行版。两名标注者先对同一批小样本独立标注，再对分歧作裁决；生成者不能单独批准自己的题。正式 gold 至少独立复核一次，争议题由第三人裁决或拒绝。

## 必填项

- seed_id、origin、domain、source ID/URL/version、问题、规范答案、别名及答案类型。
- 每跳的 head / relation / tail 与 `(doc_id, sent_id)`；路径有序且连续。
- topology、hop_count、语言、时间范围、所有合法替代路径。
- variant、pair_id、主攻击、target_hop、预期 decoy 路径/答案及来源方法。
- 自动检查、人工可回答性、唯一性、捷径检查、审核与裁决记录。

## 判断口径

1. 只依据任务协议允许的证据和知识。主集为封闭证据包：不以个人常识填补缺边。
2. 各跳有必要的支持句。删去一跳后若仍能找到唯一答案，查明另一合法路径或捷径，修改或拒绝。
3. 多篇文档不等于多跳；比较/交集图不能强套线性链，标注 depth 与必要证据边数。
4. 单因素攻击保留问题、答案和 gold。保留原文本仍需检查新增信息是否引出第二个答案或直接冲突。
5. 歧义题标 `unique` / `multiple` / `insufficient` / `clarification_required`；没有唯一答案时不能强行标原答案。
6. 逆关系多为一对多，限定时间、范围或集合，单独记录答案集合。
7. 译文保留否定、关系方向、时态、数值与限定词。反向翻译和模型评分不能替代双语阅读。

## 质检统计

统计候选通过率、拒绝原因、单位审核耗时、人工答题准确性和每项标签一致率。Cohen κ 只用于适用的类别判断，先规定单位、类别和裁决前统计；不把路径自由文本强塞进 κ。

原讨论中的 κ、98%/95% 有效率和人类下降阈值是目标建议，尚非锁定门槛。样本抽样数、误差区间和基准人类表现须一起报告；已知无效 gold 不应因总体通过率高而保留。

模板见 `annotation/`。模型可见输入不带审核字段，公开 dev 标签与输入分别导出。
